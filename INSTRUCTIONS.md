# 📍 Где находится файл books.json?

Файл с данными о книгах находится здесь:

```
public/books.json
```

## 📝 Как добавить свои книги

1. Откройте файл `public/books.json`
2. Добавьте новую книгу в массив `books`
3. Сохраните файл
4. Перезапустите приложение (`npm run dev`)

## 📋 Формат записи о книге

```json
{
  "id": "уникальный_id",
  "author": "Имя Автора",
  "series": {
    "name": "Название серии",
    "book_number": 1
  },
  "title": "Название книги",
  "cover_color": "from-red-900 to-amber-800",
  "chapters": [
    {
      "chapter_number": 1,
      "chapter_title": "Глава 1",
      "book_position": 1,
      "audio_url": "https://example.com/audio.mp3",
      "duration": 3600
    }
  ]
}
```

## 🔑 Обязательные поля

- `id` — уникальный идентификатор (латиница, без пробелов)
- `author` — имя автора
- `title` — название книги
- `cover_color` — градиент для обложки (Tailwind CSS классы)
- `chapters` — массив глав

## 🎨 Примеры градиентов

- `from-red-900 to-amber-800` — красно-оранжевый
- `from-purple-900 to-indigo-800` — фиолетовый
- `from-emerald-900 to-teal-800` — зелёный
- `from-blue-900 to-cyan-800` — синий
- `from-rose-900 to-pink-800` — розовый
- `from-yellow-900 to-orange-800` — жёлто-оранжевый

## 🔊 Аудиофайлы

Поле `audio_url` должно содержать прямую ссылку на MP3-файл.

**Поддерживаемые источники:**
- Archive.org
- Прямые ссылки на MP3
- Любые публичные аудиофайлы

**Длительность** указывается в секундах (например, 3600 = 1 час)

## ✅ Проверка

После добавления книги:
1. Запустите приложение: `npm run dev`
2. Войдите с кодом `ADMIN_2024` или `GUEST_ACCESS`
3. Ваша книга должна появиться в каталоге

## ❓ Проблемы?

Если книга не появляется:
- Проверьте синтаксис JSON (используйте [JSON Validator](https://jsonlint.com/))
- Убедитесь, что `id` уникален
- Проверьте, что файл сохранён в `public/books.json`
- Перезапустите dev-сервер
