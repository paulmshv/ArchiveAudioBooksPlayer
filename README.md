# 📚 Аудиокниги — Веб-приложение для прослушивания аудиокниг

Современное веб-приложение для прослушивания аудиокниг с поддержкой сохранения прогресса, поиска и двух уровней доступа.

![React](https://img.shields.io/badge/React-18.2.0-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5.7.0-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4.1.7-38bdf8)
![Vite](https://img.shields.io/badge/Vite-6.3.5-646cff)

## ✨ Возможности

- 🔐 **Два уровня доступа** — зарегистрированные пользователи и гости
- 📖 **Каталог книг** — коллекция русской классической литературы
- 🔍 **Поиск** — быстрый поиск по автору и названию
- 💾 **Сохранение прогресса** — автоматическое сохранение позиции прослушивания
- 🎵 **Кастомный аудиоплеер** — управление скоростью, громкостью, переключение глав
- 📱 **Адаптивный дизайн** — оптимизирован для мобильных устройств
- 🎨 **Современный интерфейс** — тёмная тема с градиентами и анимациями

## 📱 Использование

### Первый вход

1. Откройте приложение
2. Введите код доступа (например, `ADMIN_2024`)
3. Нажмите "Войти"
4. Вы будете перенаправлены на главную страницу

### Прослушивание книги

1. Найдите книгу через поиск или выберите из каталога
2. Нажмите на книгу для открытия
3. Выберите главу из списка
4. Используйте элементы управления плеером:
   - ▶️/⏸️ — воспроизведение/пауза
   - ⏮️/⏭️ — предыдущая/следующая глава
   - 🎚️ — перемотка
   - 🔊 — регулировка громкости
   - ⚡ — скорость воспроизведения (0.75x - 2x)

### Возврат к книге

1. На главной странице найдите блок "Недавно прослушанные"
2. Нажмите на книгу или кнопку "Продолжить"
3. Воспроизведение начнётся с позиции, где вы остановились (минус 10 секунд)

## 📂 Файл books.json

**Куда положить:** `public/books.json`

Приложение загружает данные о книгах из JSON-файла по пути `/books.json`. Файл должен находиться в папке `public/` — тогда он будет доступен после сборки.

### Формат файла

```json
{
  "books": [
    {
      "id": "unique_book_id",
      "author": "Имя Автора",
      "series": {
        "name": "Название серии",
        "book_number": 1
      },
      "title": "Название книги",
      "cover_color": "from-red-900 to-amber-800",
      "chapters": [
        {
          "chapter_number": 1,
          "chapter_title": "Глава 1",
          "book_position": 1,
          "audio_url": "https://archive.org/download/...",
          "duration": 3600
        }
      ]
    }
  ]
}
```

### Описание полей

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Уникальный идентификатор книги |
| `author` | string | Имя автора |
| `series.name` | string | Название серии |
| `series.book_number` | number | Номер книги в серии |
| `title` | string | Название книги |
| `cover_color` | string | CSS-классы градиента для обложки (Tailwind) |
| `chapters` | array | Массив глав |
| `chapters[].chapter_number` | number | Номер главы |
| `chapters[].chapter_title` | string | Название главы |
| `chapters[].book_position` | number | Позиция в книге |
| `chapters[].audio_url` | string | URL аудиофайла (mp3) |
| `chapters[].duration` | number | Длительность в секундах |

### Доступные градиенты для cover_color

Используйте классы Tailwind CSS:
- `from-red-900 to-amber-800`
- `from-purple-900 to-indigo-800`
- `from-emerald-900 to-teal-800`
- `from-blue-900 to-cyan-800`
- `from-rose-900 to-pink-800`
- `from-yellow-900 to-orange-800`
- и другие градиенты Tailwind

### Пример: как добавить свою книгу

1. Откройте файл `public/books.json`
2. Добавьте новый объект в массив `books`:

```json
{
  "id": "my_book",
  "author": "Автор",
  "series": {
    "name": "Моя серия",
    "book_number": 1
  },
  "title": "Моя книга",
  "cover_color": "from-blue-900 to-purple-800",
  "chapters": [
    {
      "chapter_number": 1,
      "chapter_title": "Глава 1",
      "book_position": 1,
      "audio_url": "https://example.com/audio.mp3",
      "duration": 1800
    }
  ]
}
```

3. Перезапустите приложение — книга появится в каталоге

## 📊 Хранение данных

Приложение использует `localStorage` для хранения:

- **Пользователи** — информация о зарегистрированных пользователях
- **Сессия** — токен текущей сессии
- **История прослушивания** — прогресс для каждой книги и главы

### Структура данных

```typescript
// Пользователь
interface User {
  id: string;
  user_code: string;
  user_type: 'registered' | 'guest';
  cookie_token: string;
  last_activity: string;
  created_at: string;
}

// Запись истории прослушивания
interface ListeningHistoryEntry {
  id: string;
  user_id: string;
  book_id: string;
  chapter_number: number;
  current_position: number;
  last_listened: string;
}
```

## 🐛 Известные ограничения

- Аудиофайлы загружаются с внешних источников (Archive.org)
- Данные хранятся только локально в браузере
- Нет синхронизации между устройствами
- Нет возможности экспорта/импорта данных
